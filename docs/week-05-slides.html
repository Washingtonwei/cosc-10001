AGENTS.md

# AGENTS.md

This is a Karel the Robot project for COSC 10001, a first-year course at TCU. The person asking you for help may never have programmed before.

## Rules for code you write

- Every program extends `Karel`, not `SuperKarel`. There is no `turnRight()` or `turnAround()`; if you need one, write it as a private method built from `turnLeft()`.
- Use only what the class has learned: `move()`, `turnLeft()`, `pickBeeper()`, `putBeeper()`, the conditions `frontIsClear()`, `frontIsBlocked()`, `leftIsClear()`, `leftIsBlocked()`, `rightIsClear()`, `rightIsBlocked()`, `beepersPresent()`, `noBeepersPresent()`, and `while`, `if`, `else`.
- Break every program into small methods with names that say what they do. `run()` should read like a to-do list.
- A program must work for every world of the same kind, not only the one in `worlds/`. Never count beepers or steps from a world file.
- Put each new program in its own file named after what it does, like `DoubleBeepers.java`. Do not change `MyKarel.java`.

## Checking your work

- Compile with `javac -cp lib/karel.jar *.java`. Do not run the program: it opens a window, and the student runs it themselves.
- When you finish, explain what you did in two or three plain sentences a beginner can follow.

CleanRowKarel.java

import stanford.karel.*;

/*
 * CleanRowKarel.java
 *
 * Karel should walk along the row and pick up every beeper in it.
 * Load the world long-row.w and press Run. Count what is left.
 */
public class CleanRowKarel extends Karel {

    public void run() {
        while (frontIsClear()) {
            pickUpBeeperIfThere();
            move();
        }
    }

    private void pickUpBeeperIfThere() {
        if (beepersPresent()) {
            pickBeeper();
        }
    }
}
What is a coding agent?

A chatbot talks.
An agent acts.

  • It reads the files in your folder
  • It makes a plan
  • It writes and edits files, and can run commands
  • It asks before it acts, and you say yes or no

What was wrong

Off by one

The loop stops when the wall is in front of Karel, and that's before he checks the last square.

No error. No complaint. Just one beeper left behind.
The most common bug in programming, and now you've fixed one.

If something goes wrong
  • "Do you trust this folder?" Yes, if it's your Karel folder
  • Codex says it couldn't compile because of a sandbox error: that's Codex on Windows, not your code. Just press Run
  • The agent changed something you didn't want: git restore . puts it back
  • The agent won't start at all: ask your peer mentor or in Slack. Say what you typed and the exact error
