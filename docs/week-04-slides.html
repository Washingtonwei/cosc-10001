The one place this really is dangerous

Do not try
this at home

rm -rf /deletes everything. no trash, no undo, no "are you sure?"

In 1998 somebody at Pixar ran this on the wrong folder and deleted most of Toy Story 2. It survived because a technical director working from home with a newborn happened to have a copy of the whole film.

That copy was their version control.
In six minutes you get a much better one.

The three ideas · the commands are googleable
  1. A filesystem is a tree. The icons are a costume over it.
  2. You are always standing somewhere in that tree. pwd asks where, cd walks, ls looks around.
  3. "command not found" does not mean the program is missing. It means the computer does not know where to look. That is PATH.
Run Karel from the terminal

macOS

javac -cp lib/karel.jar MyKarel.java
java -cp ".:lib/karel.jar" MyKarel

Windows

javac -cp lib/karel.jar MyKarel.java
java -cp ".;lib/karel.jar" MyKarel

One character apart. Colon on macOS, semicolon on Windows. Copy the side that is yours.

And here is the version you already know

Git is save points

Saving before the boss fightgit commit
Naming the savethe commit message
Your list of savesgit log
Load the last savegit restore .
Cloud saves, on somebody else's machineGitHub

Nobody is frightened of dying in a game. You saved. No version control is a roguelike: one run, no saves, good luck.

One difference, and Git wins

The failed run
stays in the log

Reload a save and the game forgets you died. Git keeps every attempt, including the ones that did not work.

Which is why you got to watch me change my mind about your homework.
And why I cannot quietly delete the evidence.

Three things to hold onto
  1. A commit is a save point with a note attached. You can always go back to one.
  2. The history is a story.
  3. GitHub is not Git. Git runs on your laptop. GitHub is a website that holds copies. Either one works without the other.
Break it on purpose, then undo it
# what did I just break?
git diff

# and here is it never having happened
git restore .

Not backups. The ability to try something, watch it fail, and get back to working in one command.
